
# Student Result Prediction System

## Overview
A Machine Learning project that predicts student results (Pass or Fail) based on attendance, assignment marks, quiz marks, and mid-exam marks.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Flask
- HTML and CSS
- Google Colab

## Features
- Student marks input form
- Machine Learning-based prediction
- Pass or Fail result display
- Flask web application

## Project Files
- `app.py` - Flask application
- `model.pkl` - Trained machine learning model
- `dataset.csv` - Sample student dataset
- `templates/index.html` - Web interface
- `requirements.txt` - Required Python libraries

## How to Run

1. Install Python.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open `http://127.0.0.1:5000` in your browser.

## Note
This project uses a synthetic dataset for educational purposes.
Predictions depend on the trained model and the data used during training.
